# Этап 8: проверка на Windows

Что сделать на своём компьютере, чтобы перейти с Python-версии на новую (docs/PLAN.md §6.2).
Всё делается на **копиях** серий в отдельной папке — оригиналы не трогаем.

## 1. Установить

**Установщик** (с этапа 9): [выпуски](https://github.com/sh1guchi/anitools/releases/latest) → `anitools-setup.exe` →
запустить (без прав администратора) → галочка «Команда ani» оставлена. Ставится в
`%LOCALAPPDATA%\Programs\anitools`, ярлык — в «Пуске», удаление — «Параметры → Приложения».

Без установки: `Anitools.exe` с той же страницы (или CI: **Actions** → зелёный запуск → «Artifacts» →
`anitools-win-x64`; установщик — `anitools-setup`). Собрать самому (нужен .NET 10 SDK):
```
powershell -ExecutionPolicy Bypass -File tools\windows\publish.ps1
```

## 2. Команда `ani`

Установщик добавляет папку программы в PATH пользователя и кладёт рядом `ani.exe` — батник больше не нужен.
`ani` работает в **новой** консоли (открытые до установки PATH не видят).

1. Старый `C:\personal\Scripts\ani.bat` переименовать в `ani-py.bat` (бэкап и запуск Python-версии: `ani-py`) — иначе
   он может перехватить команду, если папка `C:\personal\Scripts` стоит в PATH раньше.
2. В консоли или адресной строке проводника в папке с сериями набрать `ani` — откроется окно с этой папкой, консоль
   закроется сама (выключается в «Настройки → Прочее → Команда ani»).

## 3. Что проверить

- [ ] **Запуск `ani`** — в cmd, PowerShell и Windows Terminal; в адресной строке проводника; в корне диска (`D:\`); в папке
      с кириллицей и пробелами; `ani "D:\anime\X"`; повторный `ani` в другой папке при открытом окне — окно выходит
      вперёд и переключается. Консоль после `ani` закрывается сама (вкладка Windows Terminal — тоже).
- [ ] **Установщик и обновление** — установка, ярлык, «Удалить» в «Приложениях». Обновление: «Настройки → Прочее →
      Проверить сейчас» (когда выйдет версия новее 1.0.0) → «Обновить до …» сверху → anitools закрывается и
      открывается уже новый.
- [ ] **Программы сверху справа** — ffmpeg ✓ (версия), mkvmerge ✓, ImDisk ✓, NVENC ✓. Если что-то «!» — «Настройки» →
      «Программы» показывают, что нашлось.
- [ ] **«Установить» в настройках** — у FFmpeg и MKVToolNix «Обновить»: идёт ход скачивания, потом уведомление, пути
      ведут в `%LOCALAPPDATA%\anitools\tools\…`, версии сверху справа обновились; «Отмена» посреди скачивания —
      ничего не остаётся. ImDisk (если не стоит): запрос Windows с издателем «LAGERKVIST TEKNISK RÅDGIVNING…», окно
      установщика «Setup finished…», после — ImDisk ✓.
- [ ] **Паритет с Python** — на копии 1–2 серий прогнать п.1–7 старой и новой версией и сравнить: какие файлы
      появились, дорожки (`ffprobe`: порядок, тайтл, язык, «по умолчанию»), содержимое zip у HLS.
- [ ] **HLS на видеокарте** — серия 4K: все 6 качеств, `.mka` озвучек. Отдельно — H.264 шире 4096 (должен уйти на CPU).
- [ ] **RAM-диск** — создаётся и снимается после задачи; закрыть окно посреди задачи — диск всё равно снят.
      Без прав администратора: по «Начать» Windows один раз спрашивает разрешение («Да» — диск создаётся, «Нет» —
      сообщение с советом выбрать папку), вторая задача — без вопроса; после закрытия окна в Диспетчере задач не
      остаётся второго Anitools.exe, диск снят.
- [ ] **Отмена и закрытие** — «Отмена» в «Задачах» и закрытие окна посреди задачи: в Диспетчере задач не остаётся ffmpeg.exe.
- [ ] **Шрифты для .ass** — своя папка `C:\personal\Apps\MPV by shiguchi\fonts`, системные шрифты, скачивание
      недостающих.
- [ ] **Хардсаб** — hevc_nvenc на видеокарте, папка `Fonts\` рядом с видео.
- [ ] **Шаблон имени** («Переименовать») — набор по-русски в поле, плашки: Backspace/Delete удаляют целиком, стрелки
      перескакивают, щелчок — меню; «Условие ▾» вокруг выделенного; Ctrl+Z; «Пресеты ▾ → Сохранить как пресет…»;
      шаблон для рутрекера с `{разрешение}`, `{видео}`, `{аудио}` на настоящих сериях; после перезапуска шаблон
      и пресеты на месте.
- [ ] **Экспорт / импорт настроек** — окна сохранения и открытия файла Windows, перенос на другой компьютер.
- [ ] **Внешний вид** — масштаб экрана (DPI), шрифты, тёмная тема, перетаскивание папки на окно.

Что не так — скриншот и, если есть, лог (кнопка «Лог» у задачи; логи ошибок ffmpeg — в
`%LOCALAPPDATA%\anitools\logs`).
