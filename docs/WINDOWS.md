# Этап 8: проверка на Windows

Что сделать на своём компьютере, чтобы перейти с Python-версии на новую (docs/PLAN.md §6.2).
Всё делается на **копиях** серий в отдельной папке — оригиналы не трогаем.

## 1. Получить Anitools.exe

Один файл, .NET ставить не нужно.

- **Готовый:** GitHub → вкладка **Actions** → последний зелёный запуск на `main` → внизу «Artifacts» →
  `anitools-win-x64` (zip с `Anitools.exe`).
- **Или собрать самому** (нужен .NET 10 SDK: `winget install Microsoft.DotNet.SDK.10` или с dotnet.microsoft.com):
  ```
  powershell -ExecutionPolicy Bypass -File tools\windows\publish.ps1
  ```
  exe окажется в `C:\personal\Apps\anitools\`.

Положить `Anitools.exe` в `C:\personal\Apps\anitools\`.

## 2. Команда `ani`

1. Переименовать `C:\personal\Scripts\ani.bat` в `ani-py.bat` — это бэкап и запасной запуск Python-версии (`ani-py`).
2. Скопировать `tools\windows\ani.bat` из репозитория в `C:\personal\Scripts\`.
3. В консоли в папке с сериями набрать `ani` — откроется окно с этой папкой.

## 3. Что проверить

- [ ] **Запуск `ani`** — в cmd, PowerShell и Windows Terminal; в корне диска (`D:\`); в папке с кириллицей и пробелами;
      `ani "D:\anime\X"`; повторный `ani` в другой папке при открытом окне — окно выходит вперёд и переключается.
- [ ] **Программы внизу окна** — ffmpeg ✓ (версия), mkvmerge ✓, ImDisk ✓, NVENC ✓. Если что-то ✗ — «Настройки» →
      «Программы» показывают, что нашлось.
- [ ] **Паритет с Python** — на копии 1–2 серий прогнать п.1–7 старой и новой версией и сравнить: какие файлы
      появились, дорожки (`ffprobe`: порядок, тайтл, язык, «по умолчанию»), содержимое zip у HLS.
- [ ] **HLS на видеокарте** — серия 4K: все 6 качеств, `.mka` озвучек. Отдельно — H.264 шире 4096 (должен уйти на CPU).
- [ ] **RAM-диск** — создаётся и снимается после задачи; закрыть окно посреди задачи — диск всё равно снят.
- [ ] **Отмена и закрытие** — «Отмена» в «Задачах» и закрытие окна посреди задачи: в Диспетчере задач не остаётся ffmpeg.exe.
- [ ] **Шрифты для .ass** — своя папка `C:\personal\Apps\MPV by shiguchi\fonts`, системные шрифты, скачивание
      недостающих.
- [ ] **Хардсаб** — hevc_nvenc на видеокарте, папка `Fonts\` рядом с видео.
- [ ] **Внешний вид** — масштаб экрана (DPI), шрифты, тёмная тема, перетаскивание папки на окно.

Что не так — скриншот и, если есть, лог (кнопка «Лог» у задачи; логи ошибок ffmpeg — в
`%LOCALAPPDATA%\anitools\logs`).
