# anitools

Программа для Windows, которая готовит аниме-релизы из папки с сериями: ремукс и дорожки, сборка озвучек
в .mka, субтитры и шрифты, HLS для сайта (360p…4K в zip), хардсаб, сдвиги звука и субтитров, переименование
серий по шаблонам. Наберите `ani` в консоли в папке с сериями — anitools откроется на ней.

- Устройство программы и принятые решения: [docs/PLAN.md](docs/PLAN.md)

![anitools](docs/screenshots/main-window.png)

## Установка (Windows)

1. Скачайте **anitools-setup.exe** со страницы [выпусков](https://github.com/sh1guchi/anitools/releases/latest)
   и запустите. Права администратора не нужны. Windows может предупредить «Windows защитила ваш компьютер»
   (у программы нет цифровой подписи) — «Подробнее» → «Выполнить в любом случае».
2. В папке с сериями наберите `ani` в консоли (cmd, PowerShell, Windows Terminal) или в адресной строке
   проводника — откроется anitools в этой папке, консоль закроется сама.
3. Нет ffmpeg или MKVToolNix — нажмите «Установить» на плашке сверху: anitools скачает последние версии сам
   (Настройки → Программы; там же ImDisk для RAM-диска).

Обновления anitools проверяет сам раз в день — кнопка «Обновить» появится сверху. Без установки:
`Anitools.exe` с той же страницы — один файл.

## Шаблоны имён («Переименовать»)

Новое имя файла собирается по шаблону — редактор перенесён из Anime Uploader: переменные — плашками, условия —
рамкой, ошибки — красным с куском шаблона. Расширение остаётся своё.

| Шаблон | Что получится |
|---|---|
| `{название} - {серия}{?суффикс}.{суффикс}{/}` (стандартный) | `Sousou no Frieren - 01.mkv` |
| `{название}{?сезон≠1} S{сезон}{/} - {серия}` | `Sousou no Frieren S2 - 01.mkv` (1-й сезон — без S) |
| `{название:точки}.S{сезон:00}E{серия}.{разрешение}.BluRay.Remux.{видео}{?мульти}.{мульти}{/}.{аудио}.{каналы}-Sylvar` | `TO.BE.HERO.X.S01E01.1080p.BluRay.Remux.AVC.MULTi.FLAC.2.0-Sylvar.mkv` |

- Переменные: `{название}`, `{серия}` (01, 02…), `{сезон}`, `{суффикс}`, из старого имени — `{группа}`, `{качество}`,
  `{имя}`; из самого видео (ffprobe) — `{разрешение}`, `{видео}`, `{аудио}`, `{каналы}`, `{мульти}` (MULTi, если
  звук на нескольких языках). Субтитры и звук серии берут параметры её видео — имена совпадают.
- `{?переменная}…{/}` — кусок, только если значение есть; `{?сезон≠1}…{/}` — если сезон не 1. `{{` — обычная «{».
- `{название:точки}` — слова через точку, `{сезон:00}` — две цифры (01), `{серия:000}` — три.
- «Пресеты ▾» — готовые шаблоны и свои: «Сохранить как пресет…». Шаблон запоминается сам.
- Все настройки (с шаблонами и пресетами) — в файл и обратно: «Настройки → Прочее → Перенос настроек».

## Структура

| Папка | Что там |
|---|---|
| `src/Anitools.Core` | вся логика, без UI (.NET 10) |
| `src/Anitools.App` | GUI на Avalonia, собирается в `Anitools.exe` |
| `tests/Anitools.Core.Tests` | тесты ядра + эталоны: входы и ожидаемые ответы (`Golden/`) |
| `tests/Anitools.App.Tests` | headless-тесты окон и скриншоты |
| `installer`, `tools/windows` | установщик (Inno Setup), сборка exe и проверка установки |

## Сборка и тесты

Нужен .NET 10 SDK.

```bash
dotnet build
dotnet test
dotnet run --project src/Anitools.App -- "D:\anime\Папка с сериями"
```

Скриншоты экранов тесты пишут в `artifacts/screenshots/` (не в git). Обновить те, что лежат
в [docs/screenshots/](docs/screenshots/):

```bash
ANITOOLS_UPDATE_SCREENSHOTS=1 dotnet test tests/Anitools.App.Tests
```

Эталоны в `tests/Anitools.Core.Tests/Golden/` — зафиксированные входы и ожидаемые ответы; меняются вместе
с поведением программы (формат — в [Golden/README.md](tests/Anitools.Core.Tests/Golden/README.md)).

## Выпуск версии

1. Поднять `<Version>` в `Directory.Build.props` (например, 1.0.1) — PR, зелёный CI, merge.
2. GitHub → **Actions** → **Release** → **Run workflow** (ветка `main`). Workflow соберёт `Anitools.exe` и
   установщик, проверит установку на чистой Windows, создаст тег `v1.0.1` и выпуск с `anitools-setup.exe`,
   `Anitools.exe` и `SHA256SUMS.txt`. Установленные anitools увидят новую версию сами.
