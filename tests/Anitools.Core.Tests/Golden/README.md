# Golden-эталоны

Ответы оригинала `reference/python/anitools.py` на наборе входов. C#-тесты сверяют с ними
свою реализацию (docs/PLAN.md §5.2). Файлы не править руками — только генератором:

```bash
python3 tools/gen_golden.py          # перегенерировать
python3 tools/gen_golden.py --check  # проверить, что эталоны актуальны (так делает CI)
```

Входы: `tools/golden_inputs/filenames.txt` (~270 имён файлов), `titles.txt` (названия),
`media/` — реальный вывод ffprobe / ffmpeg / mkvmerge по сгенерированным файлам (`tools/capture_media_fixtures.py`)
и наборы прямо в `tools/gen_golden.py` (фикстуры Shikimori, дорожки субтитров, боксы MOV и т.п.).

## Формат

```json
{
  "function": "anitomy_parse",
  "description": "…",
  "source": "reference/python/anitools.py",
  "source_sha256": "…",          // по тексту с переводами строк LF
  "python": "3.13.16",
  "fixtures": { … },             // есть не у всех: общие входы, на которые ссылаются случаи
  "cases": [
    {"input": …, "output": …},
    {"input": …, "error": "ValueError"}   // оригинал бросил исключение
  ]
}
```

У части случаев есть дополнительные поля: `commands` — какие команды ffprobe/ffmpeg оригинал
запустил, `calls` — команды проходов подбора CQ с размерами выходных файлов (тест их «проигрывает»),
`api_paths` — запросы к API Shikimori, `layout` — раскладка дорожек.

Пути в эталонах HLS даны для `"platform": "windows"` (как у пользователя: `str(path)` с `\`,
сегменты через `as_posix()` с `/`) и для `"posix"`.

## Что учитывать при сравнении

- Дробные числа (CQ, битрейты) сравнивать с относительным допуском ~1e-9: `log` в разных
  библиотеках C может отличаться на последний бит. Python 3.12+ суммирует `sum()` с компенсацией
  (алгоритм Ноймайера) — для среднего битрейта повторять так же.
- `casefold()` в Python ≠ `ToLowerInvariant()` (`ß` → `ss`) — в C# это `PyText.CaseFold`/`PyText.Lower`,
  сверенные с Python для всех символов (эталон `str_casing`).
- `\w`, `\s`, `\d` в регулярках Python работают по правилам Python (`\w` = буквы + цифры + `_`,
  без диакритических знаков; `\d` — любые десятичные цифры Unicode, `int("０３") == 3`).
- `urllib.parse.quote` не кодирует `/` (а `Uri.EscapeDataString` кодирует).
- Порядок сортировки — по кодам символов; сортировка стабильная.
- Форматирование `%.2f`/`%.3f` — с инвариантной культурой.

Расхождение с эталоном допустимо только осознанно: случай помечается в тесте с причиной.
